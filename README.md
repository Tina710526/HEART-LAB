# 🧠 HEART-LAB｜心動研究所

**THE PSYCHOLOGY OF FANDOM｜從心理學看追星文化**

> 我們為什麼會對一個可能永遠不認識自己的人，產生這麼多情感？

HEART-LAB 是一份以心理學研究為基礎、以 K-pop 粉絲文化為主要案例的入門知識 Wiki。內容探索喜歡偶像的心理機制、擬社會互動、粉絲認同與社群歸屬、FoMO、收藏消費，以及健康追星與心理界線。

## 研究原則

追星不等於不理性，也不應直接被視為心理問題。本專案同時呈現追星可能帶來的快樂、支持與歸屬，也討論可能出現的焦慮、群體壓力與消費風險。所有內容盡量區分研究證據、合理推論與生活化教學情境。
