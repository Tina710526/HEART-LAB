# 🧠 HEART-LAB｜心動研究所

**THE PSYCHOLOGY OF FANDOM｜從心理學看追星文化**

> 我們為什麼會對一個可能永遠不認識自己的人，產生這麼多情感？

這是一個以心理學研究為基礎、以 K-pop 粉絲文化為主要案例的入門知識 Wiki。專案希望用容易理解、有故事感的方式，探索喜歡偶像的心理機制、粉絲社群帶來的歸屬感，以及追星過程中可能出現的壓力。

## 專案目標
- 蒐集並整理可信來源。
- 將研究內容轉化為可追溯、彼此連結的知識頁面。
- 建立概念關係圖，呈現不同心理機制如何互相影響。
- 以 Wiki 為知識庫，後續製作適合初學者的互動式 HTML 教學簡報。
- 記錄實際執行流程、錯誤節點、查核方式與改善反思。

## 研究原則
追星不等於不理性，也不應直接被視為心理問題。本專案同時討論正向經驗與可能的壓力，並區分研究證據、合理推論與生活案例。
