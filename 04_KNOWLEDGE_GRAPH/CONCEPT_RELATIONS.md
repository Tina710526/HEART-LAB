# 概念關係初稿

這是待文獻查核後持續修正的概念地圖，不代表所有關係都已被研究證實。

## 暫定主線
反覆接觸與熟悉感（S010）
→ 好感與對象印象逐步形成
→ 當下的互動感受（擬社會互動）
→ 較持續的關係感（擬社會關係）
→ 情緒投入與粉絲身分

S010 是一般心理學回顧，S001／S008 提供媒體人物與 K-pop 直播情境的 PSI／PSR 研究；此順序是教學概念圖，不是已證實的單一路徑。

### 直播情境中的 PSI、依附與忠誠（S008）
直播中的擬社會互動
→ 情感依附、持續忠誠
→ 購買意圖

- Ma et al. (2022) 以 288 位中國與韓國 K-pop 觀眾為有效樣本，研究特定解散／暫停活動表演者透過直播回歸的情境。
- 擬社會互動與情感依附（β = 0.238，p = .002）及持續忠誠（β = 0.188，p = .005）呈正向關係。
- 情感依附與持續忠誠也都與購買意圖呈正向關係。
- 懷舊經驗對情感依附與持續忠誠的預測未達顯著。
- 橫斷式問卷與 SEM 路徑不能證明因果；研究情境也不能直接代表所有偶像直播。

## 粉絲認同與社群連結路徑（S002）
K-pop 粉絲認同
→ 與同好互動、形成社會連結
→ 主觀幸福感

- Arizabal & Yabut (2025) 以 425 位菲律賓成年 K-pop 粉絲為對象，發現粉絲認同與主觀幸福感呈正向關聯。
- 研究指出，社會連結在粉絲認同與主觀幸福感之間具有顯著中介效果。
- 粉絲認同與憂鬱程度呈負向關聯；但社會連結未顯著中介粉絲認同與憂鬱的關係。
- 這是問卷相關與中介分析，不能視為追星造成幸福感提升或憂鬱減少的因果證明。
- 樣本為菲律賓成年粉絲，不能直接推廣至所有國家、年齡或 fandom。

## 線上粉絲身分與群體活動路徑（S007）
共同興趣與媒體接觸
→ 粉絲互動、串流、投票與應援
→ 線上群體認同
→ 群體比較或集體行動

- Maros & Basek (2022) 訪談 30 位活躍於 Twitter、且曾直接或間接涉及粉絲戰的 K-pop 粉絲。
- 受訪者描述的粉絲身分表現包含串流、情感支持、社群互動、粉絲活動與掌握偶像資訊。
- 研究中 90% 受訪者表示加入 fandom 後會採納部分粉絲群體認同；66.67% 表示會比較不同 fandom。
- 研究樣本刻意包含曾涉及粉絲戰者，不能推估整體粉絲群體的比例或普遍行為。
- 群體認同可能帶來歸屬、協作與資訊分享，也可能在群體比較與防衛心態下加劇衝突。

## 社群路徑
共同喜好與參與活動
→ 群體認同與歸屬感
→ 社交連結、共同記憶與支持經驗

S002 提供 K-pop 粉絲認同與社會連結、主觀幸福感之間關係的直接研究證據；S007 補充線上社群活動如何呈現粉絲身分，以及群體比較可能帶來的風險。

## FoMO 理論與追星情境路徑
### 一般心理學基礎（S005）
- FoMO：擔心他人正在經歷自己缺席的有價值經驗，並渴望持續掌握他人動態。
- 自我決定理論提供理解架構：自主感、勝任感、關係感。
- S005 發現 FoMO 與較低心理需求滿足、較低情緒／生活滿意度及較高社群媒體使用相關。
- 注意：S005 是一般社群媒體研究，不是 K-pop 粉絲研究；問卷關聯不能證明因果。

### K-pop 粉絲的經驗（S004）
社群媒體快速更新、粉絲討論與活動資訊
→ 擔心錯過偶像消息或群體共同經驗（FoMO）
→ 可能反覆查看社群、焦慮或失落
→ 在部分情況下可能壓縮休息與日常活動

S004 以 3 位高 FoMO 粉絲的質性訪談呈現這些經驗，不能據此推估普遍程度或建立因果關係。

### K-pop 粉絲的量化關聯（S006）
FoMO ↔ 問題性網路使用（PIU）
- Susaria & Pratiwi (2024) 以印尼 K-pop 粉絲為對象，採配額抽樣與問卷調查。
- 有效分析樣本 N=318；Spearman's rho = 0.703，p < .01。
- 樣本中的 FoMO 與 PIU 整體程度均被描述為中等。
- 此結果顯示正相關，不代表 FoMO 必然造成 PIU；抽樣與文化情境也限制外推。
- 摘要與方法段落出現 318／319 的數字差異，統計表格有效 N=318。

### 三篇研究如何互補
S005（一般 FoMO 定義與理論）
→ S004（K-pop 粉絲的質性經驗）
→ S006（K-pop 粉絲 FoMO 與 PIU 的量化相關）

這是不同研究提供的互補證據，不應解讀成單一研究已證明完整因果鏈。

## 健康追星與心理界線（S011 與既有來源）
粉絲認同、同好互動與社群支持（S002、S007、S009）
→ 可能帶來社會連結、幸福感與歸屬感

同時：
FoMO 與問題性網路使用（S004–S006）／心理空虛與歸屬需求、名人崇拜的關聯（S011）
→ 提醒注意自主性、日常生活功能與多元支持來源

- S011 研究的是中國成年樣本的一般名人崇拜，並非 K-pop 專屬，也不是健康追星的診斷標準。
- 目前「設定預算、保留睡眠、可自由拒絕應援」是根據自主性與生活功能原則整理的實務建議，並非某一篇研究驗證的固定處方。
- 目前缺口：直接追蹤粉絲時間管理、財務界線與自我調節的縱貫研究。

## 粉絲消費路徑（待補強）
稀有商品、限時活動與同儕分享
→ 可能產生錯失感或稀缺感
→ 可能影響購買決策

這條路徑需要更多直接研究支持，不可僅憑概念推論。
