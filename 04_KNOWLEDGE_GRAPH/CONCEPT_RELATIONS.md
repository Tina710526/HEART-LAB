# 概念關係初稿

這是待文獻查核後持續修正的概念地圖，不代表所有關係都已被研究證實。

## 暫定主線
媒體接觸與內容熟悉
→ 當下的互動感受（擬社會互動）
→ 較持續的關係感（擬社會關係）
→ 情緒投入與粉絲身分

## 社群路徑
共同喜好與參與活動
→ 群體認同與歸屬感
→ 社交連結、共同記憶與支持經驗

## FoMO 理論與追星情境路徑
### 一般心理學基礎（S005）
- FoMO：擔心他人正在經歷自己缺席的有價值經驗，並渴望持續掌握他人動態。
- 自我決定理論提供理解架構：自主感、勝任感、關係感。
- S005 發現 FoMO 與較低心理需求滿足、較低情緒／生活滿意度及較高社群媒體使用相關。
- 注意：S005 是一般社群媒體研究，不是 K-pop 粉絲研究；問卷關聯不能證明因果。

### K-pop 粉絲的經驗（S004）
社群媒體快速更新、粉絲討論與活動資訊
→ 擔心錯過偶像消息或群體共同經驗（FoMO）
→ 可能反覆查看社群、焦慮或失落
→ 在部分情況下可能壓縮休息與日常活動

S004 以 3 位高 FoMO 粉絲的質性訪談呈現這些經驗，不能據此推估普遍程度或建立因果關係。

### K-pop 粉絲的量化關聯（S006）
FoMO ↔ 問題性網路使用（PIU）
- Susaria & Pratiwi (2024) 以印尼 K-pop 粉絲為對象，採配額抽樣與問卷調查。
- 有效分析樣本 N=318；Spearman's rho = 0.703，p < .01。
- 樣本中的 FoMO 與 PIU 整體程度均被描述為中等。
- 此結果顯示正相關，不代表 FoMO 必然造成 PIU；抽樣與文化情境也限制外推。
- 摘要與方法段落出現 318／319 的數字差異，統計表格有效 N=318。

### 三篇研究如何互補
S005（一般 FoMO 定義與理論）
→ S004（K-pop 粉絲的質性經驗）
→ S006（K-pop 粉絲 FoMO 與 PIU 的量化相關）

這是不同研究提供的互補證據，不應解讀成單一研究已證明完整因果鏈。

## 粉絲消費路徑（待補強）
稀有商品、限時活動與同儕分享
→ 可能產生錯失感或稀缺感
→ 可能影響購買決策

這條路徑需要更多直接研究支持，不可僅憑概念推論。

## 待查核問題
- 粉絲社群歸屬感是否可能同時帶來支持與排除壓力？
- FoMO 與衝動購買的關係是否受自我控制或稀缺感影響？
- 追星活動與收藏是否能帶來長期的社交連結與正向心理結果？
