# 概念關係初稿

這是待文獻查核後持續修正的概念地圖，不代表所有關係都已被研究證實。

## 暫定主線
媒體接觸與內容熟悉
→ 當下的互動感受（擬社會互動）
→ 較持續的關係感（擬社會關係）
→ 情緒投入與粉絲身分

## 社群路徑
共同喜好與參與活動
→ 群體認同與歸屬感
→ 社交連結、共同記憶與支持經驗

## FoMO 路徑
社群媒體快速更新、粉絲討論與活動資訊
→ 擔心錯過偶像消息或群體共同經驗（FoMO）
→ 可能反覆查看社群、焦慮或失落
→ 在部分情況下可能壓縮休息與日常活動

S004 的質性訪談呈現了上述情境中的粉絲經驗，但因只有 3 位高 FoMO 參與者，不能據此推估普遍程度或建立因果關係。

## 粉絲消費路徑（待補強）
稀有商品、限時活動與同儕分享
→ 可能產生錯失感或稀缺感
→ 可能影響購買決策

這條路徑需要更多直接研究支持，不可僅憑概念推論。
