## 一、五條主要知識主線

### 1. 喜歡如何形成：媒體接觸與熟悉感
媒體人物／偶像內容接觸
→ 反覆接觸與熟悉感
→ 情緒投入與持續關注

- 目前證據：S001 回顧媒體人物擬社會互動與關係研究趨勢。
- 注意：這是概念導入，不應把熟悉感直接寫成必然造成喜歡的單一路徑。
- 知識頁：本階段尚需補強「心動的開始」專題研究。

### 2. 為什麼感覺像認識偶像：PSI／PSR
媒體接觸中的當下互動感（PSI）
→ 可能形成較持續的關係感（PSR）
→ 情感依附與持續支持

- S001：一般媒體人物 PSI／PSR 研究趨勢回顧。
- S008：特定 K-pop 直播回歸情境中，擬社會互動與情感依附、持續忠誠呈正向關係。
- 知識頁：[擬社會互動與擬社會關係](../02_KNOWLEDGE/02_想像中的連結/擬社會互動與擬社會關係.md)
- 限制：S008 是特定表演者與直播情境的橫斷式問卷，不能推論因果或套用到所有偶像平台。

### 3. 粉絲身分與社群歸屬
共同喜好
→ 粉絲群體身分
→ 社群互動、共同活動與社會連結
→ 可能的歸屬感與幸福感

同時也可能出現：
群體比較／群體防衛
→ 粉絲衝突與網路攻擊風險

- S002：菲律賓成年 K-pop 粉絲的粉絲認同、社會連結與主觀幸福感相關研究。
- S007：Twitter K-pop 粉絲線上社會認同與 fandom 活動質性研究。\n- S009：全球 BTS 粉絲在 Weverse 的粉絲互動、心理幸福感與虛擬社群歸屬感研究。
- 知識頁：[粉絲認同、社會連結與正向心理社會結果](../02_KNOWLEDGE/03_我們的粉絲宇宙/粉絲認同與正向心理社會結果.md)\n- S009 補充：粉絲彼此互動與擬社會關係，均可能與虛擬社群歸屬感相關；研究聚焦 BTS／Weverse，且為問卷資料。
- 知識頁：[線上粉絲身分與 fandom 活動](../02_KNOWLEDGE/03_我們的粉絲宇宙/線上粉絲身分與%20fandom%20活動.md)
- 限制：S002 不能證明追星造成幸福感；S007 樣本刻意包含曾涉及粉絲戰的活躍 Twitter 使用者，不代表一般粉絲。

### 4. 喜歡的代價：FoMO、網路使用與消費
社群更新與群體活動
→ 擔心錯過資訊或共同經驗（FoMO）
→ 可能增加反覆查看與網路使用
→ 可能影響休息與日常生活

- S005：一般社群媒體情境中的 FoMO 理論與測量基礎。
- S004：少數高 FoMO K-pop 粉絲的質性經驗。
- S006：印尼 K-pop 粉絲 FoMO 與問題性網路使用的量化相關。
- 知識頁：[錯失恐懼與追星社群](../02_KNOWLEDGE/04_喜歡的代價/錯失恐懼與追星社群.md)
- 知識頁：[FoMO 的心理學基礎與測量](../02_KNOWLEDGE/04_喜歡的代價/FoMO的心理學基礎與測量.md)
- 知識頁：[FoMO 與問題性網路使用：K-pop 粉絲研究](../02_KNOWLEDGE/04_喜歡的代價/FoMO與問題性網路使用_K-pop粉絲研究.md)
- 注意：S005 是一般社群媒體研究；S004 樣本僅 3 人；S006 為相關研究，均不能推論必然因果。

### 5. 收藏與消費的情感意義
小卡、專輯與周邊收藏
→ 情感記憶、身分表達與社群交換
→ 也可能牽涉花費、稀缺與收藏壓力

- S003：11 位 K-pop 粉絲／收藏者的質性碩士論文研究。
- 知識頁：[小卡收藏的情感與社群意義](../02_KNOWLEDGE/04_喜歡的代價/小卡收藏的情感與社群意義.md)
- 限制：樣本小、研究情境特定，且為學位論文，不能視為所有收藏者的共同經驗。
- 待補強：消費決策、稀缺行銷、衝動購買與粉絲經濟的直接研究。

## 三、目前知識缺口

1. **心動的開始**：熟悉感、情緒、獎勵與注意力等機制需要更直接的心理學研究。\n2. **健康追星**：需要更多關於心理界線、情緒調節、自主選擇與平衡生活的研究。
2. **健康追星**：需要更多關於心理界線、情緒調節、自主選擇與平衡生活的研究。
3. **消費壓力**：稀缺感、限時販售、抽卡與衝動購買需要更直接的粉絲情境證據。
4. **文化與平台差異**：目前來源涵蓋菲律賓、印尼、馬來西亞／東南亞、台灣以外的不同情境，但各研究樣本與平台差異大，不可直接合併推論。

## 四、教學建議順序
1. 從「為什麼會心動」引起好奇。
2. 說明 PSI／PSR，理解親近感如何出現。
3. 轉到粉絲身分與社群歸屬。
4. 呈現 FoMO、網路使用與可能壓力。
5. 以收藏和消費案例討論情感與選擇。
6. 最後回到如何保有自主、界線與生活平衡。

## 五、品質原則
- 關聯不等於因果。
- 研究樣本不等於所有粉絲。
- 一般媒體／社群研究不等於 K-pop 專屬研究。
- 質性研究適合理解經驗，不適合推估盛行率。
- 每一個教學主張都應回到來源頁，並保留研究限制。
