# 來源品質檢查表

每筆文獻整理前後都要檢查以下項目。請依照實際取得的版本與核對範圍標示狀態，不要只因為找到摘要或搜尋結果就標成全文已核對。

## 基本資料
- [ ] 找到原始出版頁面或正式全文。
- [ ] 作者、年份、標題與出版資訊一致。
- [ ] DOI 或原始網址可用。
- [ ] 確認文章類型：實證研究、系統性回顧、敘述性回顧、理論文章或學位論文。

## 研究內容
- [ ] 摘要與研究目的已閱讀。
- [ ] 樣本、研究情境或文獻回顧範圍已記錄。
- [ ] 方法與測量方式已記錄（若適用）。
- [ ] 主要發現有原文依據。
- [ ] 研究限制已記錄。
- [ ] 已區分相關性、統計預測與因果性。

## Wiki 轉寫
- [ ] 白話解釋沒有擴大原文結論。
- [ ] K-pop 案例清楚標示為研究情境、應用或延伸說明。
- [ ] 每項重要主張都能追溯到來源。
- [ ] 已連結相關概念頁面。
- [ ] 未核對內容明確標示「待核對」。

## 查核狀態定義
| 狀態 | 使用條件 | 是否計入全文已核對 |
|---|---|---|
| 全文已核對 | 取得正式全文或可確認的作者稿，並核對研究目的、方法、樣本、結果、討論與限制 | 是 |
| 全文已取得；核心章節已核對 | 有完整全文，已核對與 Wiki 主張直接相關的章節，但未逐章完整整理 | 否，另列統計 |
| 摘要已核對 | 只取得正式摘要、書目或資料庫紀錄 | 否 |
| 全文待取得／版本待確認 | 只有第三方副本、搜尋片段，或無法確認稿件版本 | 否 |

## 接受標準
只有取得可確認的全文版本，並能追溯研究方法、主要結果與限制，才可標示為「全文已核對」。只有搜尋摘要或二手轉述時，不可算作完整收錄。若全文已取得但只核對核心章節，請使用「全文已取得；核心章節已核對」，不要混用「全文已核對」。
