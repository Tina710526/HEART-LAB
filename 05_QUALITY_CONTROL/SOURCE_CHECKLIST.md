# 來源品質檢查表

每筆文獻整理前後都要檢查以下項目。

## 基本資料
- [ ] 找到原始出版頁面或正式全文。
- [ ] 作者、年份、標題與出版資訊一致。
- [ ] DOI 或原始網址可用。
- [ ] 確認文章類型：實證研究、系統性回顧、敘述性回顧、理論文章或專書章節。

## 研究內容
- [ ] 摘要與研究目的已閱讀。
- [ ] 樣本、研究情境或文獻回顧範圍已記錄。
- [ ] 方法與測量方式已記錄（若適用）。
- [ ] 主要發現有原文依據。
- [ ] 研究限制已記錄。
- [ ] 已區分相關性與因果性。

## Wiki 轉寫
- [ ] 白話解釋沒有擴大原文結論。
- [ ] K-pop 案例清楚標示為研究情境、應用或延伸說明。
- [ ] 每項重要主張都能追溯到來源。
- [ ] 已連結相關概念頁面。
- [ ] 未核對內容明確標示「待核對」。

## 接受標準
只有完成基本資料與核心內容核對，並能追溯主要主張的來源，才可標示為「已核對」。只有搜尋摘要或二手轉述時，不可算作完整收錄。
