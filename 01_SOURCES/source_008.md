# S008｜K-pop 直播中的擬社會互動、情感依附與持續支持

## 書目資料
Ma, Z., Song, L., Zhou, J., Chong, W., & Xiong, W. (2022). How do comeback Korean pop performers acquire audience empathetic attachment and sustained loyalty? Parasocial interactions through live stream shows. *Frontiers in Psychology, 13*, 865698.

- DOI：https://doi.org/10.3389/fpsyg.2022.865698
- 出版社正式全文：https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2022.865698/full
- PubMed Central：https://pmc.ncbi.nlm.nih.gov/articles/PMC8996109/
- 文章類型：量化橫斷式問卷研究。
- 理論架構：依附理論、忠誠理論與擬社會互動理論。

## 研究目的
研究聚焦曾經解散或暫停活動、後來透過直播重新與觀眾接觸的 K-pop 表演者，探討直播中的擬社會互動、懷舊經驗與表演者吸引力，如何與觀眾的情感依附、持續忠誠及購買意圖相關。

## 研究方法與樣本
- 研究採橫斷式線上問卷。
- 問卷發送給中國與韓國的 K-pop 舞蹈學校／社團成員。
- 共發出 700 份問卷，回收 302 份，其中 288 份可用。
- 有效樣本中，61.1% 為中國籍、38.9% 為韓國籍；73.6% 為女性。
- 87.5% 受訪者年齡為 20–24 歲。
- 研究使用結構方程模型（SEM）檢驗變項之間的路徑關係。

## 主要研究結果
1. 直播中的擬社會互動與觀眾的情感依附呈顯著正向關係（標準化係數 β = 0.238，p = .002）。
2. 擬社會互動也與持續忠誠呈顯著正向關係（β = 0.188，p = .005）。
3. 表演者被觀眾感知到的持續吸引力，與情感依附（β = 0.263，p < .001）及持續忠誠（β = 0.412，p < .001）呈正向關係。
4. 情感依附與持續忠誠均與直播產品的購買意圖呈正向關係。
5. 研究中的懷舊經驗並未顯著預測情感依附或持續忠誠。

## 白話理解
直播讓粉絲不只是觀看表演，也可能透過留言、回應與即時交流，產生「好像正在和偶像互動」的感受。這種擬社會互動感，在本研究的特定情境中，與更強的情感依附及持續支持意願有關。

這也提醒我們，粉絲感受到的親近感可能受到平台互動設計影響；但直播中的互動感不等於雙方已建立平等、私人的現實關係。

## 解讀限制
- 研究對象是中國與韓國的 K-pop 舞蹈學校／社團成員，且限定為曾支持解散團體、可能回歸直播的觀眾，並非所有一般 K-pop 粉絲。
- 有效樣本為 288 人，且年齡集中於 20–24 歲，外推至其他年齡或文化需謹慎。
- 橫斷式自陳問卷與結構方程模型可檢驗變項關係，但不能證明因果。
- 研究情境是特定的「解散／退團表演者透過直播回歸」，不能直接套用到所有現役偶像直播或付費訊息平台。
- 作者指出，未來研究可使用實驗、個案研究及其他文化樣本，進一步檢驗這些關係。
